# IAM-Basics
Project exploring basic concepts in Identity and Access Management

# Simulated Company

FinTech trading firm with: Traders, Developers, Managers, Human Resources.

## Tech Stack

- Rocketchat
- Gitea
- postgreSQL
- MailPit
- midPoint
- Keycloak

## Roles

- human_resources
- trader
- developer
- manager

# IAM Features

## SSO, JML, RBAC, SoD, Access Certification, etc.

- Single Sign On via Keycloak
- Role-Based Access Control
- Automated Access Provisioning and Deprovisioning (coming soon)
